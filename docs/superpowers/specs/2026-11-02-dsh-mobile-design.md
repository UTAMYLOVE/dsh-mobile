# dsh 手機版（DSH Mobile）設計規格書

日期：2026-11-02
決策者：宇哥
狀態：設計已口頭確認，待書面審閱

> 本專案與 openclaw-v4（BTC 交易公司）無關，將放在獨立的新 GitHub 私人倉庫。此文件暫存於此，建倉後搬過去。

## 1. 目的與動機

宇哥喜歡用官方 DeepSeek Harness（dsh，DeepSeek 開源代理人框架，2026-08 發布，MIT 授權），尤其是多代理人（Subagent）與智能體團隊（Agent Teams）。但現在只能在電腦上跑，電腦得一直開著。

目標：做一個 **Android App**，讓官方 dsh 完全在手機上獨立運作，電腦可以關掉；並加入 OpenClaw 風格的**記憶**與**心跳**，讓它放在口袋也能自己醒來整理記憶、主動做事、跳通知提醒。

選擇自己做 App 而不用 Termux 腳本或社群 APK 的原因：
- 腳本安裝太麻煩，要的是「裝 APK、點圖示就能用」。
- 社群 APK（DSHBox、DeepSeek Harness Mobile 等）權限過多、可完全控制手機、程式碼來路不明，而且沒有多代理人與智能體團隊。

## 2. 用途與目標裝置

主要用途：查資料、寫規格書、聊天。不會跑超長任務。

目標裝置：Samsung Galaxy S25 Ultra（SM-S9380），Android 17，One UI 9.0。第一期只需保證這台；minSdk 由實作者訂，但不必為舊版 Android 做額外相容。

**背景子行程限制（phantom process）**：Android 12+ 會殺掉超量或忙碌的背景子行程，proot + Node + 多代理人 + Shell 會撞到。Android 14+ 可在「開發人員選項」關閉「子行程限制」。宇哥同意做這個一次性設定：App 首次啟動時要有**引導畫面**，一步步帶他打開開發人員選項並關閉該限制（App 只引導、不自行修改系統設定），並在設定頁顯示目前是否已關閉；未關閉時代理人數預設自動降為保守值並提示。

## 3. 目標、非目標、反目標

**目標**
- 官方 dsh 原封不動在手機上運作，介面版面與功能與官方一致（只換配色），官方插件（Agent Teams、Subagent、Shell、網頁搜尋等）全部可用。
- 多代理人、智能體團隊規模「越多越強越好」：可調上限，預設開到 API 撐得住的程度。
- OpenClaw 風格記憶（從零開始）。
- 心跳：手機鎖螢幕、App 不在前景時也會定時觸發，結果用手機通知送達。
- 支援 DeepSeek 官方 API 與 Claude API（Claude 金鑰之後才會有）。
- App 內一鍵更新官方 dsh，失敗可自動或手動退版。
- 介面配色：A「櫻花淺粉」。

**非目標（第一期不做）**
- 語音輸入（不申請麥克風權限）。
- 語意（向量）記憶搜尋：手上的 DeepSeek 與 Claude 都沒有 embedding 服務，第一期只做關鍵字搜尋。
- 整套 OpenClaw Gateway、聊天頻道（Telegram 等）。
- 搬移電腦上 `~/.openclaw` 的舊記憶。
- iPhone 版。
- 接入 openclaw-v4 交易系統。

**反目標（就算能跑也算失敗）**
- 申請超出第 6 節清單的權限，尤其是無障礙服務、檔案/相簿、通訊錄、簡訊、定位、相機、麥克風。
- 修改官方 dsh 原始碼，或用自寫介面取代官方介面。
- 金鑰明文寫入檔案、記錄檔或程式碼。
- 手機上其他 App 能透過本機連線操作 dsh。
- 心跳或代理人在無人察覺下大量燒錢。

## 4. 已決定的技術路線

**執行環境：APK 內建精簡 Linux（proot + Debian + Node.js 24）。**
- dsh 需要 Node ^22.19.0 或 >=24.0.0；Node 24 滿足。
- 不採用直接打包 Android 版 Node（Termux bionic 版）：Node 會回報平台為 `android`，官方套件的原生模組（如 SQLite）常編譯失敗，與「一鍵更新跟官方一致」衝突。
- 不採用 nodejs-mobile：Node 版本太舊。
- 接受代價：APK 與首次解壓後佔用約 300～500MB，啟動慢數秒。

**App 外殼：Kotlin 原生 Android App。**

## 5. 架構

### 5.1 App 外殼
- **主畫面**：全螢幕 WebView 顯示官方 dsh 網頁介面（`dsh web`，預設 `127.0.0.1:3080`）。
- **設定頁**：API 金鑰、代理人規模、預算、更新/退版、匯出錯誤記錄、今日花費。
- **常駐服務（Foreground Service）**：啟動並守護 dsh 行程；通知列常駐圖示（Android 規定）。
- **心跳排程**：用 Android 系統鬧鐘機制（AlarmManager 類）定時喚醒，呼叫 dsh 執行心跳任務。
- **通知橋接**：接收 dsh 通知插件的請求，發出手機通知；點擊打開對應對話。
- **匯出**：透過 Android 系統分享選單 / 「另存新檔」選擇器匯出檔案，不需要儲存權限。

### 5.2 內建 Linux 環境
- Debian rootfs、Node.js 24、官方 `@deepseek-ai/dsh`（鎖定一個已驗證的初始版本）。
- 全部位於 App 私有空間。

### 5.3 自寫 dsh 插件（兩個）
官方 dsh 一行不改，只外加插件（dsh 基於 Cordis，一切皆插件）。

**記憶插件**（照 OpenClaw 設計）
- 工作區內的 Markdown 檔：`MEMORY.md`（長期記憶，每個新對話載入；與 dsh 原生會讀的 `MEMORY.md` 共用同一份）、`USER.md`（偏好與個人背景）、`memory/YYYY-MM-DD.md`（每日筆記，自動載入今天與昨天）。
- 工具：`memory_search`（關鍵字搜尋）、`memory_get`（讀指定檔案/行範圍）、寫入記憶。
- 對話壓縮前提示代理人先存重要內容。
- **做夢**：由心跳觸發，定期把每日筆記中值得留的內容整理進 `MEMORY.md`。
- 記憶從零開始。

**通知插件**
- 提供給代理人一個「傳手機通知給宇哥」的工具，交由 App 外殼發送。

### 5.4 心跳
- 手機在口袋、App 不在前景時也要觸發；**開機後自動恢復**（RECEIVE_BOOT_COMPLETED）。
- 每次心跳**只做記憶整理（做夢）**，不主動查新聞、不跑排程任務、不追未完成對話。整理出值得提醒的事才發通知。
- App 不在前景時 dsh 不常駐：鬧鐘到 → 冷啟動 dsh → 做夢 → 關閉。App 在前景時 dsh 常駐。
- 使用不精確鬧鐘即可（30～60 分鐘間隔），不需要精確鬧鐘權限。
- 沒網路或 API 錯誤：本次跳過，下次再試，不重試轟炸。

### 5.5 模型與團隊
- 支援 DeepSeek API 與 Claude API。優先使用官方現成的模型接口插件；沒有才自寫。
- 可設定：同時執行代理人數、分派層數、團隊人數。預設高於官方的 8 個，開到 API 速率限制可承受的程度。
- 重要角色（總指揮、審查者）可用較強模型，跑腿子代理人用便宜模型；Claude 金鑰到手後適合放在總指揮。
- 沒有 Claude 金鑰時，只用 DeepSeek 也要完整可用。

### 5.6 費用
- 設定頁顯示今日花費。
- 預設每日超過 US$5 時通知一次，不暫停（此數字為主腦預設，可改）。
- 硬性上限（超過就暫停新任務、等確認）可在設定頁開啟，預設關閉。

## 6. 權限與安全

**只申請**：網路、前景服務（類型 `specialUse`，避開 `dataSync` 每日 6 小時上限）、保持喚醒、通知、忽略電池最佳化（首次啟動時請使用者同意）、開機完成廣播（讓心跳開機後恢復）、安裝應用程式（外殼自我更新，系統逐次詢問）、查看網路狀態（WorkManager「有網路才跑」條件）。共 9 個，2026-11-02 宇哥同意後兩項。

**金鑰**：使用者在設定頁輸入，以 Android Keystore 加密保存。**金鑰永遠不交給 dsh**：dsh 的模型請求指向 App 內的本機代理，由代理補上金鑰再轉送到 DeepSeek / Claude。如此代理人執行 `env`、讀 `/proc` 都看不到金鑰；代理同時負責統計每日花費（5.6）。金鑰不寫入任何設定檔或記錄檔。若官方網頁搜尋插件需要第三方金鑰，同樣走設定頁 + Keystore + 代理。

**本機存取保護**：dsh 只綁 `127.0.0.1`。因同手機其他 App 也能連 localhost，每次啟動產生隨機通行碼，只有本 App 的 WebView 帶得出來；沒有通行碼的 HTTP 與 WebSocket 請求一律拒絕。優先用 dsh 插件掛載驗證；若插件做不到，用 Node 啟動前置載入（`--require`）包住 HTTP 伺服器做驗證，**不修改官方原始碼**。本機金鑰代理同樣要求通行碼。

**Shell 工具**：代理人可在內建 Linux 中執行指令，但被限制在 App 私有空間，碰不到手機其他資料。

## 7. 更新與退版

- **dsh 更新**：設定頁「檢查更新」顯示官方最新版號；更新時裝到新資料夾、保留舊版。新版啟動後自動健康檢查（介面能開、兩個自寫插件有載入）；失敗自動退回舊版並通知原因。可手動退版。
- **外殼 App 更新**：程式碼倉庫維持私人；GitHub Actions 把簽好的 APK 發佈到一個**公開的下載位置**（APK 內不含任何金鑰）。App 定期檢查新版，有新版就跳通知，點一下下載並交給系統安裝（需「安裝未知應用程式」的使用者授權，由系統逐次詢問）。

## 7.1 匯出與備份

- 工作區內任何檔案（規格書、資料）都能從 App 匯出（系統分享選單 / 另存新檔）。
- 記憶（`MEMORY.md`、`USER.md`、`memory/`）可一鍵整包匯出備份，避免移除 App 時全部消失。
- 單一工作區，記憶檔放在該工作區內。

## 8. 錯誤處理

- dsh 當掉：自動重開；連續 3 次就停止，通知使用者選「退版」或「查看錯誤記錄」。
- 錯誤記錄可從設定頁匯出，內容不含金鑰。

## 9. 打包與測試

- 新的 GitHub 私人倉庫，與 openclaw-v4 分開。
- GitHub Actions：每次提交自動跑測試並打包 APK；不需要宇哥的電腦。
- 測試在雲端 Android 模擬器實際啟動 dsh，確認：介面能開、通行碼保護生效、記憶插件能寫檔、心跳能發出通知、更新失敗能退版。全過才發佈。
- APK 用宇哥的簽章金鑰簽名（讓新版能覆蓋舊版安裝）；簽章金鑰由宇哥自行填入 GitHub Secrets，主腦不經手。

## 10. 留給實作者決定的部分

- 精簡 Debian rootfs 的來源與裁剪方式、proot 的整合方式。
- WebView 注入粉紅配色的做法（CSS 覆蓋或 dsh UI 主題插件），以不改官方原始碼為原則。
- 心跳預設間隔（建議 30～60 分鐘，可在設定頁調）。
- 代理人數的實際預設值（依 DeepSeek 速率限制實測）。
- 記憶插件與 dsh 原生 `MEMORY.md` 共用時的具體整合點。

## 11. 主腦代為決定的事項（宇哥可推翻）

- 每日 US$5 通知門檻、硬上限預設關閉。
- dsh 連續當掉 3 次停止重開。
- 規格書暫存在 openclaw-v4 倉庫、不提交到交易分支。
- 通行碼做不到插件掛載時，改用 Node 前置載入包住伺服器（不改官方原始碼）。
- 金鑰改由 App 內本機代理注入，dsh 拿不到金鑰。
- 加「開機完成」權限；前景服務類型用 `specialUse`。
- App 不在前景時 dsh 不常駐，心跳冷啟動。
- 單一工作區；工作區檔案與記憶可匯出備份。

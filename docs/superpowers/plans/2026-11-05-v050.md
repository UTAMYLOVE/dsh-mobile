# DSH Mobile 0.5.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship 0.5.0: the fixes already on the branch plus all 24 features of the approved design, inside the existing screens.

**Architecture:** dsh already has fork, search, plan mode, todos, schedules and `present`; the app adds RPC wrappers, reads the
`todos`/`plan`/`workingDirectory` projections, ships five new app skills, and builds the UI pieces in the existing chat, dock
and list screens. App-only state (pins, locks, temporary chats, projects, helpers) lives in small JSON/SharedPreferences
stores under the app's files.

**Tech Stack:** Kotlin, Jetpack Compose (BOM 2026.01.01), Robolectric unit tests (`--max-workers=2`), the emulator e2e suite
(`E2eTest`, `FakeModel`), AndroidSVG (`com.caverock:androidsvg-aar:1.4`) for SVG, Android `TextToSpeech`, `RecognizerIntent`,
`ActivityResultContracts.TakePicture`, `KeyguardManager`.

**Spec:** `docs/superpowers/specs/2026-11-05-v050-design.md`; mockups https://claude.ai/artifact/2tT9tm2YSXdkeeo3cbL1PB

## Global Constraints

- Colors only: `#FEDFE1`, `#DC9FB4`, `#A5DEE4`, `#D7C4BB`, `#9E7A7A`, `#5E4445`, `#7D5F60`, `#A98F90`, white, alpha tints (use `Sakura.*` / `War.*`).
- Numbers in Chakra Petch; Orbitron only for large English titles. Layouts must hold at font scale 1.3 and 393 dp width.
- Exactly the nine declared permissions; no CAMERA, RECORD_AUDIO, USE_BIOMETRIC.
- Official dsh unmodified; paths only through `DshLayout`; both proot and native modes work.
- Keys stay in the Keystore; no telemetry; no `.env`.
- All UI copy in Traditional Chinese, plain words; touch targets ≥ 44 dp; every new control has a `Tags.*` test tag.
- Commit trailers: `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` and `Claude-Session: https://claude.ai/code/session_01TjBB5vvKdwZye97QPVXiMw`.
- Push only to `claude/dsh-mobile-cloud-handoff-vfhvdh`; version 0.5.0, versionCode 9; only the owner tags.

## Review Focus

1. A conversation whose events are paged out (very long, 500K context): edit/re-answer/branch and the contents drawer must still find the right `seq` (Task 2, Task 11 tests use a paged state).
2. A reply with no follow-up block, a malformed one, or one in the middle of streaming: nothing breaks and no marker text ever shows (Task 3).
3. Voice/camera/lock activities missing on the device (no recognizer, no camera app, no screen lock set): a plain message, never a crash (Tasks 4, 9).
4. A helper whose schedule dsh no longer has (deleted in chat) or a project folder deleted by the agent: the page shows it as gone, nothing hangs (Tasks 10, 12).
5. Native vs proot: projects and helpers created in one mode, opened in the other, go through the existing other-mode prompt (Task 10 test).
